Đã làm

  • Electron 44.3.0, React 19.2.8, Vite 8.2.2, Tailwind 4, shadcn/ui, Zustand; TypeScript strict và pnpm-lock.yaml khóa dependency.
  • Main/preload/renderer tách biệt; sandbox, contextIsolation, CSP và IPC kiểm tra sender/session/payload.
  • Chụp toàn màn hình, chọn vùng trên ảnh đóng băng, chuyển tọa độ DIP sang bitmap; backend dự phòng lấy một frame thật trong cửa sổ cô lập rồi dừng stream.
  • Shortcut toàn cục cấu hình được, transaction rollback khi conflict, lưu qua restart; tray, single instance và cleanup phiên.
  • Editor theo pixel gốc: màu/độ dày, mũi tên, chữ nhật/vuông Shift, tròn, bút tự do, blur, chọn/đổi màu/xóa, Escape và Cancel.
  • Blur dùng ảnh gốc đã làm mờ và mask; annotation màu ở trên. Cache CPU và chỉ render vùng thay đổi; chung pipeline preview/PNG export.
  • Copy bằng API clipboard bất đồng bộ của Electron 44; Save qua dialog native, ghi PNG, nhớ thư mục, giữ ảnh khi hủy hoặc lỗi.
  • NSIS installer Windows x64 chưa ký; giữ logo/icon hiện có. Script cài runtime có checksum và giải nén bằng Windows.

Kiểm chứng

  • Typecheck và production build: đạt. Vitest: 8 file, 19 test đạt.
  • Electron thật: chụp toàn màn hình/vùng chọn, đủ tool, clipboard Windows, PNG Save khớp hash pixel, hủy Save, Escape và fallback frame đều đạt.
  • Shortcut conflict bằng đăng ký thật và lưu qua restart đạt; 30 chu kỳ capture/cancel luôn trở lại một cửa sổ Settings.
  • Fixture 4K trong Electron: pixel blur/mask/overlap/layer order/restoration/export đạt. Render/readback p95 cuối 2,7 ms; không thay cho đo độ trễ toàn giao diện trên màn hình 4K thật.
  • Bản Screenshot.exe đã đóng gói: 4/4 E2E đạt, không dùng Vite, gồm 30 chu kỳ và backend fallback.
  • Môi trường: Windows 10 build 19045 x64, i5-1145G7, Node 24.21.0; hai màn hình 100% DPI (1920×1080 và 1920×1200 bên trái).
